# Audio streaming probes

Original 3-second stereo sine tones, 44.1 kHz: 440 Hz left and 660 Hz right,
amplitude 0.15. Generated with NumPy and libsndfile (via soundfile 0.14.0),
encoded as Ogg/Vorbis, FLAC PCM16 and MP3 Layer III. No third-party recording.
The fixtures are covered by this repository's license. Test execution does not
require soundfile or an external encoder.
