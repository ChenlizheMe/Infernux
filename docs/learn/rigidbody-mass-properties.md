# 刚体的显式质量属性

普通刚体继续根据 Collider 几何推导质心和惯量。导入机器人或其它已有物理数据的模型时，可以直接指定质量、局部质心、主惯量及其方向：

```python
body.set_mass_properties(
    mass=0.2,                       # kg
    center=(0.01, 0.02, 0),          # 刚体局部坐标，m
    moments=(0.001, 0.002, 0.0025),  # 质心处的三个主惯量，kg·m²
    rotation=(0, 0, 0, 1),           # xyzw；主轴转到刚体局部轴
)
```

这些值描述单位对象缩放下的物体。`mass_properties` 返回这份显式配置；返回 None 表示使用几何推导。`reset_mass_properties()` 恢复几何推导并保留总质量。之后修改 `body.mass` 会按质量比例调整显式惯量。

质量至少为 0.001 kg；质心和主惯量有限，主惯量为正并满足物理三角不等式，旋转为非零有限四元数。当前缩放下的逆惯量也必须可表示。质量属性设置先验证候选，再发布属性和物理配置；不把非法或很小的惯量替换成其它形状的惯量。

质心和惯量进入同一套原生形状、质量配置管道。质心偏移保留碰撞几何位置；创建、缩放、Collider 重建和自由度重配都读取同一份配置。形状质心变化继续通知现有关节，不重新定义它的零姿态。旋转冻结仍按世界轴生效。

非均匀或镜像缩放按固定总质量变换二阶矩，再恢复惯量张量。单轴压平如果仍形成有效平面惯量，可以正常使用；退化到不可表示的配置会报告错误。很小的有效张量先归一化分解，再恢复真实逆惯量，避免触发通用求解器的小惯量球体替代规则。配置期间的检查不需要逐帧执行；显式配置保存在组件冷数据中，物理热池的布局不增加这份负担。

场景文档和克隆保存同一份局部事实：显式配置写在 Rigidbody 的 `mass_properties` 字段中，包含 center、moments 和 rotation；缺少该字段表示几何推导，不使用格式版本号或备用解释路径。

桌面 NNNP1 的 Microduck 项目用这套接口接入官方几何、质心和完整惯量。原始 STL 转为标准 OBJ/MTL，通过普通模型资产管道加载。模型的 Z-up 转为引擎 Y-up，关节弧度和碰撞类别保留。已有物理 actor 由 Collider 持有，因此不声明碰撞几何的部件使用禁碰撞层中的载体 Collider，其形状不决定质量或惯量。

项目中的有限扭矩关节控制依据源 kp、黏性系数和两端刚体的轴向有效惯量换算频率/阻尼参数。当前被动阻尼并入电机，因此也受同一扭矩上限；未饱和小动作下的换算成立，不声称高速饱和时与原动力学逐项一致。它没有复现官方训练环境的完整 BAM、摩擦损失和关节 armature；物理接入和神经图驱动通过，也不等于强化学习行走已经完成。
