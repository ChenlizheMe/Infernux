TUTORIALS / TWO ENTRY POINTS

Build your way into Infernux.

Start with the five minute path, or open a complete course. Both routes land in the same deterministic engine loop.

Infernux 0.4.1 · Windows

Get started

Five steps from an empty machine to a cube spinning under your own Python. No environment to assemble, no build system to learn first.

1

Install InfernuxHub

Download InfernuxHub and open it. The Hub looks after your engine versions, your projects, and the Python runtime behind each one, so you never have to wire up an interpreter by hand.

Download InfernuxHub
2

Install an engine version

  1. Open Installs in InfernuxHub.
  2. Pick the Infernux version you want and install it.
  3. Go to Projects, create a project, and point it at that version.

Keep as many engine versions installed as you like. Every project pins its own, so upgrading one project leaves the rest untouched.

3

Get your bearings in the editor

Hierarchy
Everything in the current scene, scene objects and UI alike.
Scene
Where you move, rotate and arrange things.
Game
Exactly what the active Camera renders.
Inspector
The components and values on whatever you have selected.
Project
Scenes, scripts, materials, textures and every other asset.
Console
Errors, warnings and anything your scripts log.
4

Run a scene

  1. Create or open a scene.
  2. If it is empty, drop in a Cube, a Camera and a light.
  3. Save with Ctrl + S.
  4. Press Play and watch the Game window.

Nothing on screen? Check that the scene has an enabled Camera, then read the first error in Console. The first one is almost always the real one.

5

Write your first Python component

Create Spin.py in your project, then add Spin to a GameObject from the Inspector.

import infernux as inx


class Spin(inx.InxComponent):
    speed: float = inx.serialized_field(default=90.0, range=(0.0, 360.0))

    def update(self, delta_time: float) -> None:
        self.transform.rotate(inx.Vector3(0.0, self.speed * delta_time, 0.0))

Save the scene and hit Play. The object turns, and Speed is right there in the Inspector, editable while the game runs. That is the whole loop: an ordinary Python class, one lifecycle method, and a field the editor knows how to show.

Infernux 0.4.1 · Windows

开始使用

五步，从一台干净的电脑到一个由你自己的 Python 驱动、正在转动的方块。不用配环境，也不用先学一套构建系统。

1

安装 InfernuxHub

下载并打开 InfernuxHub。引擎版本、项目，以及每个项目背后的 Python 运行环境，都由它照看，你不需要自己去接解释器。

下载 InfernuxHub
2

装一个引擎版本

  1. 在 InfernuxHub 里打开安装页面。
  2. 挑一个 Infernux 版本装上。
  3. 回到项目页面新建项目，把它指向刚装好的版本。

想装多少个版本都行。每个项目锁定自己的那一个，升级其中一个项目不会动到其他项目。

3

先认认编辑器

Hierarchy
当前场景里的一切，场景物体和 UI 都在这儿。
Scene
移动、旋转、摆放东西的地方。
Game
当前 Camera 真正渲染出来的画面。
Inspector
你选中的那个物体身上的组件和数值。
Project
场景、脚本、材质、贴图，以及其他所有资产。
Console
错误、警告，还有你脚本打的日志。
4

跑起一个场景

  1. 新建或打开一个场景。
  2. 如果它是空的，丢进去一个 Cube、一个 Camera 和一盏灯。
  3. 按 Ctrl + S 保存。
  4. 点 Play，盯着 Game 窗口。

什么都没有？先确认场景里有一个启用的 Camera，然后去 Console 看第一条错误。第一条几乎总是真正的那条。

5

写下第一个 Python 组件

在项目里新建 Spin.py，然后在 Inspector 里把 Spin 挂到一个 GameObject 上。

import infernux as inx


class Spin(inx.InxComponent):
    speed: float = inx.serialized_field(default=90.0, range=(0.0, 360.0))

    def update(self, delta_time: float) -> None:
        self.transform.rotate(inx.Vector3(0.0, self.speed * delta_time, 0.0))

保存场景，点 Play。物体转了起来，Speed 就在 Inspector 里，运行时也能随手改。整个循环就这么多：一个普通的 Python 类，一个生命周期方法，一个编辑器认得出来的字段。
