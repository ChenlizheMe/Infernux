# 路线图状态核查（2026-10-04）

后续细化：图谱已扩展至 2,951 个节点。原有 131 个已实现叶节点保持原状态，新增 1,904 个细化目标均显式标为规划项，等待逐项实现核查；这不表示这些目标的所有相关代码都不存在。新增 119 个专题父节点按子节点聚合状态。节点源数据已移至 `docs/data/roadmap/*.json`，`docs/js/roadmap-data.js` 仅保留按需加载索引。每张图谱的节点数均超过扩展前的三倍。

渲染细化涵盖体积云、参与介质、光追加速结构、MIS、路径积分和降噪。MIS 的采样与权重术语参照 [PBRT 的采样效率章节](https://pbr-book.org/4ed/Monte_Carlo_Integration/Improving_Efficiency)，光追后端边界参照 [Khronos Vulkan Ray Tracing 指南](https://docs.vulkan.org/guide/latest/extensions/ray_tracing.html)。这些是规划依据，不是引擎已实现证据。

核对对象是当前本地工作区的实现、公开 API 和测试源码，而不是仅按 README 或文件名推断。`live` 表示该节点所述能力已有可用实现，不代表整个子系统完成、全部平台验收或无缺陷。`partial` 仅由子节点聚合生成，表示分支有已实现能力和剩余目标；它不表示正在开发。按维护者要求，本轮不指定任何 `progress`。

`planned` 表示仍在规划或尚未确认完成的目标，不能据此断言仓库中完全没有相关代码。未找到足够证据的目标不升级；网络复制、完整神经模型运行时、批量世界及确定性回放继续保持规划/远期研究。编辑器历史事务不作为模拟回放的证据，SoA 和计算缓冲不作为完整张量数据面的证据，动画状态机不直接等同于通用 AI 决策系统。

本轮新增标记 **81 个已实现叶节点**。下表覆盖本轮所有状态升级，并注明实现边界。此前已有的基础节点保留原状态；这份记录不宣称对全部规划目标完成运行验收。测试文件链接证明仓库已有对应验证代码，本轮只运行网站检查，没有运行引擎全量 pytest、原生测试或物理设备验收。
