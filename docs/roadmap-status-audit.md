# 路线图状态核查（2026-10-10 精简与逐项核对）

本轮按维护者要求，对十张星图的每一个叶节点逐项核对：保留、删除或调整状态。此前为把节点数扩到原来三倍而补入的细化目标中，有大量重复、过细或空泛的条目；本轮将其删除，图谱从 2,951 个节点精简为 1,720 个。网站检查 `test-roadmap-data.mjs` 不再要求“原节点数三倍”，改为要求每张图至少 6 个分支、每个分支至少 3 个目标。

删除标准：与同图或其他图谱节点重复；只是把上层目标拆成实现步骤；没有可交付结果的空泛条目；由依赖库（如 Jolt）内部完成而非引擎需要交付的算法；超出本引擎范围。状态标准不变：`live` 必须有具体源码文件与符号作为证据（多数另有测试），不按关键词、依赖库能力或 TODO 推断；`future` 表示远期研究，`planned` 表示可落地的工程目标；本轮不指定 `progress`。下表中的每一项 `live` 升级都经过脚本校验，确认所列文件存在且包含所列符号；仍有若干升级的实现范围窄于节点名称，“范围说明”列逐条写明了边界。本轮未运行引擎全量测试。
