# 048 到 050 迁移记录

048 来源提交为 `5424d0e93`。以 `b5eba5c42` 为基线，共核对 529 个变更路径。迁移并入 `050/recreate_rendering_physical` 的 World、渲染和物理结构。冲突处按 050 的接口接回功能。

## 在 050 中使用的实现

| 范围 | 迁移结果 |
| --- | --- |
| 自动化 | 操作、异步任务、查询、信号和回合汇报由引擎 Automation Host 提供。MCP 作为独立进程连接 Host。Automation SDK 随引擎 wheel 安装，也可以单独使用。 |
| MCP 制品 | `external/plugins/infernux_mcp` 固定到 `76e7fd03110f6b9ba9c45d55c07e228251929165`（`v0.3.0`）。CMake 使用子模块的 `package.py` 生成内置包。插件目录使用同一标签的 GitHub Release。 |
| 插件和主题 | 插件安装选择兼容版本。更新覆盖发布者的文件，保留用户新增文件。资源管理器和插件共用同一源码加载入口，检查引擎版本、依赖启停和循环依赖。停用时清理包源码注册的回调。已加载的原生扩展被外部替换时停止旧服务，错误进入资源诊断。主题在插件面板安装，在独立的主题面板选择。主题模板包含手稿、金属、磁带和浅色样例。 |
| 脚本热重载 | 脚本通过 050 的编辑和运行 World 一起发布。当前保存版本失败时，停用旧执行并保留组件 ID 和字段。初始化失败的组件暂停执行，修复源码后重新初始化。编辑器命令和场景手柄随所属源码注销。 |
| 资源和场景 | 损坏资源记录到导入诊断。同一个编译失败只在控制台保留一条记录。托管音频预览和单次播放解析当前资源，纹理准备失败进入资源诊断。未保存场景遇到外部修改时保留编辑内容，已保存场景可以直接重载。场景加载事务在完成预制体和资源准备后才结束。 |
| 渲染脚本和图 | 失效的管线、效果和粒子产物停止提交。修复后从当前源重新构建。 |
| 编辑器界面 | 接入主题入口和资源选择图标。顶栏搜索与布局使用同一行对齐。编辑器与 Player 共用 Maple Mono CN，ImGui 编译时关闭内置字体。截图完成由原生采集回调发出信号。 |

## 验证

- Windows Release 原生构建与 wheel 打包通过。wheel 为 45.53 MiB，唯一随包分发的字体是 `MapleMono-CN-Regular.ttf`。内置 MCP 包与 `v0.3.0` 远程制品逐字节一致。制品检查通过 23 个原生二进制的依赖检查，以及 Slang 的 SPIR-V 和 WGSL 编译检查。
- 实际编辑器验证插件安装、主题分类、场景加载和 MCP 异步截图。截图通过完成信号交付。最终 wheel 上的五项编辑器测试通过，覆盖 MCP 截图、外部 SDK、损坏项目启动、插件资源报错和元数据更新。
- 最后一轮迁移专项覆盖插件生命周期、脚本失败与修复、受损资源导入、场景加载、编辑器界面和 Web 输入桥接，364 项通过，3 项跳过。独立 Vulkan 用例通过，验证 RenderStack 在源码损坏时停止提交，源码修好后恢复输出。最终 wheel 的编辑器内置脚本热重载测试通过。
- Python 全量运行 4,483 项，3,953 项通过、492 项失败、26 项出错，12 项跳过。数量最多的失败来自仍然直接调用 Play 的测试，050 要求先准备运行 World。原始 050 代码复现了同一错误。
- Windows 原生全量运行 251 项，194 项通过，57 项失败，其中 19 项超时。主题、截图、窗口输入、字体、音频和资源索引等相关原生测试通过。该次全量运行早于迁移专项的最后修补。
- Windows wheel 进程隔离全量检查运行 639 项，513 项通过，126 项失败。全量运行后修复了原生扩展外部替换，并更新了 MCP 和 Play 的测试入口。相关专项 16 项通过。最后重建的 wheel 上，原生插件、运行状态回执、脚本声明和 UI 的 5 项复验均通过。
- Hub、发布和契约测试共 384 项通过，9 项按平台条件跳过。固定 MCP 插件的 21 项测试通过。
- 迁入的 68 项原始回归用例覆盖插件兼容性、源码重载、组件查询依赖、回调清理和 Vulkan 管线故障恢复，并在 050 上通过。
- `test_render_texture_asset.py` 的 8 项相机与纹理测试、逐字符文本几何测试以及文件监听字体重载测试，在迁移前的 050 代码上也可复现。
- 纹理刷新失败和缓存驻留的 3 项测试也在迁移前的 050 Python 源码与同一套 Windows 原生制品上复现。
- Web Release Player 完成全量构建，制品通过 `wasm32` 与 `cp313` 清单检查、JavaScript 语法检查和 Wasm 模块验证。链接器报告 NumPy 的 `random_multinomial` 签名差异。Web 插件独立测试有 32 项通过、3 项失败和 2 项收集错误，涉及过时的着色器和构建接口。Linux 和 Android 实机验证属于待验项。
