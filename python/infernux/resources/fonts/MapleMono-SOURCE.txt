The font is an unmodified upstream hinted static TTF. Only Regular is bundled.
CN supplies Chinese glyphs with a two-to-one CJK/Latin advance ratio.
Font coverage does not imply that every Unicode character is supported.
OpenType programming ligatures require shaping support in the text renderer;
bundling this font does not enable ligatures in the engine by itself.
